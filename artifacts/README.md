# Generated Research Artifacts

This directory will contain artifacts generated from versioned evidence and benchmark outputs.

Planned artifact classes:

## Literature/evidence artifacts

- publication and capability timelines
- technology/problem evolution diagrams
- problem × method matrices
- problem × metric matrices
- evidence-maturity heatmaps
- reproducibility matrices
- standards/research coverage matrices
- cross-layer dependency graphs
- contradiction/trade-off graphs
- validated-gap tables

## Experimental artifacts

- baseline comparison tables
- latency/QoE/energy trade-off plots
- scalability curves
- adaptation-under-shift curves
- convergence/sample-efficiency plots
- Pareto-front analyses where appropriate
- ablation and sensitivity results

## Provenance rule

Every generated figure/table must be traceable to:

1. a versioned input dataset/result;
2. a script;
3. a workflow run or reproducible command;
4. the software revision used to generate it.

Manually edited numerical plots are not accepted as final research artifacts.
