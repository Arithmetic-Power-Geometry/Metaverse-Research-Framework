# Paper-Ready Results

This is the canonical manuscript-facing output directory.

Every table, figure, algorithm/pseudocode specification, analysis dataset, and adversarial review that may later support the COMST manuscript is copied or generated here with provenance.

## Structure

- tables/ — manuscript-facing evidence tables
- figures/ — generated figures plus source-data references
- algorithms/ — benchmark/algorithm specifications only after fidelity gates
- data/ — normalized source data behind tables/figures
- reviews/ — adversarial IEEE/COMST reviewer reports
- runs/ — run summaries and provenance

## Admission rule

An item is paper-ready only when its source evidence is versioned, unresolved fields are explicit, and no unresolved CRITICAL/HIGH reviewer finding affects the promoted claim.

This directory is not the manuscript and must contain no manuscript-generation instructions.
