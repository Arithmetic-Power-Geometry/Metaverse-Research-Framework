# Algorithm A05 — Security Evidence Gate
1. Identify protected asset and trust boundary.
2. State adversary/threat model.
3. Record security/privacy property.
4. Classify evidence: conceptual, formal, simulation, prototype, attack experiment, testbed, deployment.
5. Record assumptions.
6. Record workload, scale, overhead and baselines.
7. Check standards/interoperability separately.
8. Check artifact and independent reproduction separately.
9. Block ranking when threat models/properties differ materially.
10. Promote gaps only after contrary protocols, standards and implementations are searched.
