# Algorithm A09 — Digital-Twin Metric Semantics Gate
1. Identify what is synchronized: state, model, service, sub-metaverse or semantic representation.
2. Record freshness metric exactly: AoI, desynchronization time, state error/NRMSE, latency or update rate.
3. Record communication and compute resource model.
4. Record whether energy is directly measured, analytically estimated or represented by request/transmission counts.
5. Record topology, dynamics and physical-process model.
6. Record baseline and evaluation protocol.
7. Block numerical ranking when synchronization targets or metric semantics differ.
8. Allow qualitative lineage comparison with explicit qualifications.
