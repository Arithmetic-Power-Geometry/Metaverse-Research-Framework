# Algorithm A11 — Dataset Reuse Gate
1. Verify dataset-producing publication and persistent identifier.
2. Record modality, subjects/devices, task, duration and environment.
3. Record raw versus processed data availability.
4. Record schema/documentation.
5. Record collection/preprocessing code separately.
6. Record license and access restrictions.
7. Record persistent archive separately from mutable repository.
8. Search for independent downstream reuse.
9. Never equate public dataset with full experiment reproducibility.
10. Use dataset for cross-paper comparison only when workload and metric semantics are compatible.
