# Algorithm A06 — Security Gap Falsification
1. Normalize gap by asset, adversary, property and scope.
2. Search standards/work items separately.
3. Search protocols/formal analyses.
4. Search prototypes, attack evaluations and testbeds.
5. Search artifacts/reproductions.
6. Search deployment/adoption.
7. Reject broad gap if contrary mechanism satisfies it.
8. Otherwise narrow to evidence/conformance/reproduction/deployment limitation.
9. Record contrary evidence and residual assumptions.
