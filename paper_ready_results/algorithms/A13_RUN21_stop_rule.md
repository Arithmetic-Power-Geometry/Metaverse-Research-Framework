# Algorithm A13 — Literature Saturation Stop Rule
1. Require all planned evidence domains to have primary and/or authoritative coverage.
2. Require closest-review and contrary-evidence coverage.
3. Require master bibliography >= 200 verified records.
4. Reject additions whose only value is increasing reference count.
5. Permit post-freeze additions only for: metadata correction, promoted-claim evidence, contrary evidence, or documented coverage defect.
6. Record each permitted late addition and its reason.
7. Hand corpus to gap validation.
Output: RUN21 CLOSED or CONTINUE WITH SPECIFIC DEFECT.
