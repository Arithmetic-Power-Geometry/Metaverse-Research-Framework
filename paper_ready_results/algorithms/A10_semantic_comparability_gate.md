# Algorithm A10 — Semantic-Communication Comparability Gate
1. Identify source modality and downstream task.
2. Record semantic representation/model.
3. Record channel/network and compute assumptions.
4. Record semantic metric exactly.
5. Record conventional-communication baseline and conversion rule, if any.
6. Record task utility/quality metric separately from transmission efficiency.
7. Record dataset/workload and semantic-model training provenance.
8. Block numeric ranking if modality, semantic metric, task or resource model differs materially.
9. Permit qualitative comparison only with explicit evidence-class labels.
