# Algorithm A12 — Testbed–Artifact Link Gate
1. Identify peer-reviewed study and exact experimental topology.
2. Record devices, wireless technology, rendering/streaming stack and workload.
3. Identify persistent dataset/software artifact and version.
4. Verify artifact corresponds to the reported experiment.
5. Record raw traces, processed data, scripts and configuration separately.
6. Record whether study can be rerun from artifact or only reanalyzed.
7. Search independent reuse/reproduction separately.
8. Never infer field-wide reproducibility from one strong artifact-positive lineage.
9. Preserve topology/workload limits when citing quantitative results.
