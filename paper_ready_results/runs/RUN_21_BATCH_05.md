## Novelty consequences
Broad AI-for-Metaverse surveying is occupied. Broad GenAI-for-Metaverse surveying is occupied. Generative-VR surveying is occupied. Ethical/legal GenAI+Metaverse synthesis is occupied. Distributed-ML/privacy synthesis is occupied.

The manuscript must therefore avoid generic novelty claims in these areas. AI/GenAI papers should instead be mapped by task, model/method, workload/data, baseline, metric, compute/network context, evidence maturity, artifact availability, deployment maturity and cross-paper comparability.

## Evidence-class rule for AI/GenAI
Separate:
- SURVEY/REVIEW
- CONCEPTUAL_FRAMEWORK
- OFFLINE_EVALUATION
- PROTOTYPE/TESTBED
- USER_STUDY
- OPERATIONAL_DEPLOYMENT
- REUSABLE_ARTIFACT
A model/application description is not deployment evidence.
