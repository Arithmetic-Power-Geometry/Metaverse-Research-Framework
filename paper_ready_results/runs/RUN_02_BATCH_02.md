# RUN 02 — Closest-Review Saturation, Batch 02

## New evidence

Batch 02 targeted the strongest remaining novelty risks: reproducibility, evidence maturity, benchmarking, resource-management requirements, standards/tutorial breadth, and empirical-evidence reviews.

### Major novelty attacks

1. **MetaverseBench (2023)** already proposes a holistic systems benchmark methodology and implemented benchmark suite.
2. **XRBench (MLSys 2023)** already provides open-source XR/Metaverse ML benchmark workloads with explicit tasks, models, datasets and performance requirements; archived paper plot data are available.
3. A **2026 AI-Metaverse review** explicitly discusses public datasets and reproducibility issues.
4. A **2026 systematic review of network resource management in multi-user XR** occupies part of the communications/resource-management requirements space.
5. A **2026 multidimensional Metaverse maturity model** means generic maturity-model novelty is unsafe.
6. A **2024 empirical Metaverse review** focuses explicitly on empirical studies.

## Revised candidate novelty

After these attacks, the contribution must be narrower and stronger:

**Cross-domain communications-centric evidence normalization for networked Metaverse research, connecting each technical claim to problem definition, algorithm/method, workload/dataset, baseline, metric, hardware/network environment, evidence maturity, artifact-level reproducibility and deployment maturity, with explicit comparability gates and contrary-evidence falsification of proposed gaps.**

This remains a candidate until saturation and full-text comparison are complete.

## Prohibited headline novelty claims

- first networked Metaverse survey;
- first comprehensive Metaverse survey;
- first architecture taxonomy;
- first maturity model;
- first evidence-based Metaverse review;
- first Metaverse benchmark;
- first XR benchmark;
- first resource-allocation benchmark;
- first discussion of reproducibility;
- first open-problem/gap analysis.
