# Figure F04 — Evidence Type × Artifact Expectation Matrix

Primary algorithm/system study → code/config/environment/run instructions expected when computational
Benchmark suite → executable harness + workloads/data + configuration expected
Dataset resource → persistent data + schema/documentation expected
User/field study → protocol/instrument/material availability considered separately
Survey/review → secondary evidence; excluded from primary artifact denominator
Standard → normative evidence; excluded from research-artifact denominator
Operational deployment → deployment evidence; public code may be legitimately unavailable

Purpose: prevent a single reproducibility rubric from being applied mechanically to fundamentally different evidence units.
