# Figure F08 — Security Dataset-to-Deployment Transfer

Generic network/IoT dataset
→ preprocessing/sampling
→ trained detector
→ held-out benchmark result
→ cross-dataset validation
→ Metaverse-like testbed traffic
→ adversarial/red-team evaluation
→ operational immersive deployment

Evidence strength increases to the right, but stages are not automatically cumulative.

Key warning:
high benchmark accuracy ≠ measured operational Metaverse security.
