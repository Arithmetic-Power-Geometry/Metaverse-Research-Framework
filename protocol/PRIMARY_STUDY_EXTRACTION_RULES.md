# Primary Study Extraction Rules

## Evidence hierarchy

For primary technical studies, prefer:

1. publisher full text or publisher metadata;
2. accepted-author manuscript / institutional repository;
3. author preprint corresponding to the peer-reviewed version;
4. authoritative bibliographic database;
5. secondary review only for discovery or cross-checking.

## Minimum record before comparison

A study must have, where applicable:

- verified title, authors, year, venue, DOI;
- problem definition;
- system model;
- decision variables;
- objective(s);
- constraints;
- algorithm/method;
- baselines;
- workload/dataset/simulator;
- key environment assumptions;
- metrics;
- evaluation form;
- artifact/code status.

Missing fields are marked unknown rather than inferred.

## Comparison rule

Reported values from different papers are not placed in a common numerical ranking unless the comparability tuple is sufficiently aligned.

## Frontier rule

Preprints are stored in the frontier set and clearly labeled. They may help detect emerging directions but cannot alone establish a mature literature gap.

## Version rule

When a peer-reviewed version is found, link the preprint to it and treat the peer-reviewed version as the principal bibliographic record while preserving version-specific differences when relevant.
