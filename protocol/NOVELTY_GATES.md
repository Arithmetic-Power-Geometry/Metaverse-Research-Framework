# Novelty Gates

A proposed contribution is retained only if it survives the relevant gate.

## N1 — Broad survey gate

Existing broad Metaverse surveys already cover definitions, technologies, applications, and challenges. Therefore these elements are necessary tutorial material, not sufficient novelty.

## N2 — Resource-allocation gate

A 2024 Computer Science Review survey reports comparison of 35 edge-enabled Metaverse resource-allocation strategies and benchmarking of 19 algorithms. Therefore a generic resource-allocation taxonomy or algorithm table is not sufficient novelty.

## N3 — Technology-specific gate

Dedicated reviews already exist for AI, blockchain, interoperability, security/privacy, distributed learning, sustainability, fault management, and other focused areas. Technology-by-technology coverage alone is not sufficient novelty.

## N4 — Gap-list gate

Future-work lists and author-reported challenges are not sufficient. A major gap must be supported by systematic evidence and a contrary-evidence search.

## N5 — Algorithm gate

A new algorithm is justified only when:

1. a specific technical problem is established;
2. relevant existing algorithm families are identified;
3. comparable baselines can be implemented or reliably evaluated;
4. a measurable limitation remains under a common protocol;
5. the proposed method addresses that limitation;
6. the evaluation includes appropriate baselines, ablation/sensitivity where applicable, and statistical support.

## N6 — Candidate distinctive contribution

The current candidate is an evidence-centered synthesis linking:

problem → method/algorithm → workload/dataset → baseline → metric → environment → evidence maturity → reproducibility → standards/deployment → cross-layer trade-off.

This is not yet declared novel. It must be tested against the expanded closest-review corpus.
