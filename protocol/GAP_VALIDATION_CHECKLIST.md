# Gap Validation Checklist

A candidate gap is promoted to a validated gap only when all applicable checks are completed.

## Literature checks

- [ ] Broad keyword search completed
- [ ] Synonyms/alternate terminology searched
- [ ] Foundational literature checked
- [ ] Latest literature checked through freeze date
- [ ] Closest surveys checked
- [ ] Backward snowballing completed
- [ ] Forward snowballing completed
- [ ] Contrary evidence explicitly searched

## Implementation checks

- [ ] Public code searched
- [ ] Supplementary material searched
- [ ] Public datasets/workloads searched
- [ ] Benchmark/testbed papers searched
- [ ] Relevant standards/specifications checked
- [ ] Industry/open-source implementation evidence checked where scientifically relevant

## Comparability checks

- [ ] Problem definitions aligned
- [ ] Metrics formally compared
- [ ] Dataset/workload compatibility assessed
- [ ] Environment assumptions assessed
- [ ] Baselines assessed
- [ ] Evaluation protocol assessed

## Gap statement checks

- [ ] Gap is narrower than a generic "more research is needed" statement
- [ ] Evidence supporting the gap is recorded
- [ ] Evidence contradicting/limiting the gap is recorded
- [ ] Scope and time boundary are explicit
- [ ] Gap does not depend solely on absence of search results
- [ ] Gap is testable or leads to a concrete research question
- [ ] Second reviewer/agent validation completed

## Promotion states

- candidate
- evidence-supported
- validated
- invalidated
- superseded
- unresolved

Only **validated** gaps may be presented as firm open problems.
