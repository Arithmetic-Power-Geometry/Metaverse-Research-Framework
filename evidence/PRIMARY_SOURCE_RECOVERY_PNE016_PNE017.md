## PNE017

Authoritative IEEE metadata confirms publication in IEEE Transactions on Wireless Communications, vol. 24, no. 7, pp. 6135–6150, July 2025, DOI 10.1109/TWC.2025.3551938.

The public full-text/preprint record provides additional workflow detail. A documented illustrative configuration uses 100 FPS, slot duration tau = 10 ms, MTP threshold = 20 ms, and background prediction-window length L = 5. The paper models foreground/background processing queues, optimizes rendering decisions and MEC resource allocation, and minimizes sensor-information age and mobile-device power subject to the MTP constraint using AQM-CUP.

The L=5 value is stored as an illustrative workflow setting unless the experimental section confirms it as a benchmark parameter.

## PNE016

Authoritative IEEE metadata confirms publication in IEEE Transactions on Mobile Computing, vol. 24, no. 10, pp. 10247–10263, October 2025, DOI 10.1109/TMC.2025.3569695.

The paper defines EdgeVRQoE using rendering delay and visual quality; models GPU, CPU and outbound bandwidth as leased multidimensional rendering resources; formulates a double-layer decision problem; and uses a hybrid-action multi-agent reinforcement-learning dynamic resource auction mechanism. The abstract reports at least an 18-fold QoE improvement against representative schemes. That reported relative result is provenance evidence only and is not imported as a benchmark expectation.
