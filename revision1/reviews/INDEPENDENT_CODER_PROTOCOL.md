# Independent-coder validation protocol

This file prepares, but does not fabricate, the independent reliability analysis requested by the COMST-style review.

## Sampling target
A genuine second human coder should independently re-code a stratified 20-30% sample spanning networking/edge/XR, digital twins, semantic communication, AI/GenAI, security/privacy, standards/interoperability, sustainability, datasets/testbeds, and foundations/applications.

## Fields to recode
- declared primary domain
- evidence role (primary, secondary/review, normative/standard, dataset/testbed, deployment/application)
- comparability dimensions P,W,D,H,N,B,M,E where applicable
- C0-C3 class where applicable
- artifact audit state / R0-R4 inputs where applicable
- gap-evidence role (supporting, contrary, neutral/not-applicable)
- evidence class / evaluation setting

## Agreement analysis
After the second coder returns the blinded coding sheet, compute raw agreement and Cohen's kappa for categorical fields with sufficient support. Report disagreements before adjudication, then retain an adjudicated consensus version separately.

## Scientific status
No second-coder kappa value is present in this package because no genuine independent second coding has been supplied. This limitation must remain explicit in the manuscript until human recoding is completed.
