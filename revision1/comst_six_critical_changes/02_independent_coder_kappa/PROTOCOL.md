# 2. Independent second-coder validation and kappa

## Requirement
A genuine second human coder must work independently and blinded to the first-coder labels.

## Minimum sample
Use a stratified 20-30% sample of the 200-record corpus, with representation from:
networking/edge/XR, digital twins, semantic communication, AI/GenAI, security/privacy, standards/interoperability, sustainability, datasets/testbeds, and foundations/applications.

## Fields
- primary_domain
- evidence_role
- P,W,D,H,N,B,M,E when applicable
- C_class when applicable
- artifact audit inputs / R_class when applicable
- gap_evidence_role
- evidence_class

## Analysis
Report raw agreement and Cohen's kappa for supported categorical fields. Preserve the pre-adjudication coder sheets. Create a separate consensus file after disagreements are resolved.

## Integrity boundary
This folder intentionally contains no kappa value until a genuine independent coder returns completed labels.
