# Coder B — independent recoding package

Target: 50 records (25% of the frozen 200-record corpus), stratified by primary domain.

Allocation: networking/edge/XR 10; digital twin 5; semantic communication 4; AI/GenAI 6; security/privacy 8; standards/interoperability 2; sustainability 5; datasets/testbeds 3; foundations/applications/other 7.

Fields: primary domain, evidence role, P/W/D/H/N/B/M/E, C-class, artifact state, gap-evidence role, evidence class, notes, coder initials, date, and human verification.

This folder is intentionally unfilled. It becomes independent-coder evidence only after a different human coder personally codes the frozen sample without seeing Coder A judgments. Raw agreement, Cohen's kappa, and weighted kappa must be calculated only after both independent coding sheets are frozen.

A prepared Excel workbook with validation lists and agreement sheets accompanies the working package outside GitHub when binary upload is unavailable through the repository connector.
