# P1 — Prospective reproducible search and PRISMA

This folder contains the complete prospective protocol needed to remove the historical-search reconstruction problem.

## Files
- FORMAL_DATABASE_QUERY_PROTOCOL.md — frozen query logic and database translations.
- SCREENING_AND_DEDUP_PROTOCOL.md — deterministic deduplication and screening rules.
- search_execution_ledger.csv — database execution ledger.
- full_text_exclusion_ledger.csv — one primary exclusion reason per excluded full text.
- PRISMA_COUNTS_TEMPLATE.csv — calculation targets for PRISMA 2020.
- PUBLIC_WEB_VALIDATION_2026-10-06.csv — publisher-targeted validation evidence.
- P1_MANUSCRIPT_TEXT.tex — defensible manuscript wording.
- P1_EXECUTION_STATUS_2026-10-06.md — exact completion boundary.

## Integrity rule
Formal database counts must come from actual database sessions/exports. Public-web discovery is coverage validation and must never be relabeled as Scopus, Web of Science, IEEE Xplore, or ACM database counts.
