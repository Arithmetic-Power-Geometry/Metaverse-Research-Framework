\subsubsection{Prospective Search Validation}
Because the original historical query ledger was not fully recoverable, we preregistered a fresh prospective corpus-validation search rather than reconstructing historical counts. The protocol fixes the concept blocks, database-specific query translations, eligibility rules, deduplication procedure, exclusion taxonomy, and PRISMA fields before formal database execution. The required core databases are IEEE Xplore, Scopus, Web of Science Core Collection, and ACM Digital Library, with ScienceDirect and SpringerLink used only as predeclared supplementary coverage sources. A publisher-targeted public-web validation run on 6 October 2026 confirmed current literature across the intended technical strata, but the execution environment did not expose authenticated Scopus/Web of Science sessions or reproducible database-result counts. Consequently, no formal PRISMA identification count is inferred from web-search results. Database-specific counts will be reported only from preserved exports generated by the formal database sessions.
