# COMST six-critical-changes work package

This folder operationalizes the six highest-impact revisions requested for the Metaverse COMST manuscript.

## Status legend
- **Completed from frozen evidence**: can be executed from the repository's current evidence package without inventing data.
- **Prepared, external validation required**: protocol/template/codebook completed, but a genuine independent human/database execution is still required.
- **Blocked by external access**: cannot be honestly completed from the present execution environment.

## Six changes
1. Fresh database search + PRISMA — **prepared; formal database execution remains external**.
2. Independent second coder + kappa — **prepared; genuine second-human coding required**.
3. Audit all reproducibility-eligible studies — **eligible-denominator workflow specified; full study-level audit requires primary-artifact inspection beyond the current 12-row registered audit**.
4. Validate C0-C3 on 150-200 stratified pairs — **sampling/design and analysis schema prepared; final coding requires study-level pair coding**.
5. Extract gap claims systematically from previous surveys — **systematic extraction schema and normalization protocol prepared**.
6. Quantify security, sustainability, AI, and network evidence across eligible denominators — **denominator-based counting specification prepared from the current 200-record role map and domain matrices**.

## Scientific-integrity rule
No PRISMA counts, kappa coefficients, R0-R4 prevalence, pair-distribution percentages, or domain-prevalence statistics are invented. Every value must come from executed searches, independent coding, or completed audits.
