# 6. Denominator-based quantification of network, AI, security, and sustainability evidence

## Networking
Freeze eligible networking denominator from the 38 networking/edge/XR records. Code mechanism, objective, evaluation regime, artifact maturity, and cross-paper comparability.

## AI/GenAI
Freeze eligible primary-study denominator from the 25 AI/GenAI records. Code RL/MARL, FL, edge AI, foundation/multimodal, GenAI, and agent categories plus evaluation regime and artifacts.

## Security
Freeze eligible primary-study denominator from the 32 security/privacy records. Code evidence level:
generic benchmark, transferred benchmark, native immersive, physical/testbed, operational.

## Sustainability
Freeze eligible primary-study denominator from the 18 sustainability records. Code:
proxy, analytical/modelled energy, simulation-based energy, measured joules, carbon accounting, LCA.

## Required reporting
For every domain, report n/N_eligible and percent only after all eligible rows are coded.
