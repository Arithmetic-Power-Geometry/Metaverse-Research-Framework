# P3 evidence-calibration cases

These cases calibrate the eight-field audit against sources with unusually explicit reproducibility information.

## Mapping used
R0 = 0-1 verified audit fields.
R1 = 2-3 verified audit fields.
R2 = 4-5 verified audit fields.
R3 = 6-7 verified audit fields.
R4 requires all eight fields, including independently verified reproduction.

A public repository alone is not R4. "Available upon request" is not counted as public code/data or persistent archive.

These post-freeze cases must not be inserted into the frozen-200 prevalence denominator unless they are matched to an existing frozen record or the corpus protocol is formally amended.
