# 5. Systematic extraction and falsification of prior-survey gap claims

## Source set
Use a predefined corpus of the closest Metaverse/networked-Metaverse surveys.

## Extract verbatim gap statements containing signals such as
lack of, limited, remains unexplored, open challenge, future work, little research, insufficient, absent, missing.

## Normalize
Map semantically equivalent statements to a canonical proposition while preserving:
- source survey
- page/section
- original wording
- year
- domain
- normalization rationale

## Falsification
For each normalized proposition search:
1. closest reviews
2. primary studies
3. datasets/testbeds/artifacts
4. standards where relevant

Decision: CONTRADICTED, NARROWED, or RETAINED.

## Required headline result
Report both statement-level and normalized-proposition-level denominators.
