# Paper Writing Evidence Master

This folder is the manuscript-facing evidence index for the Metaverse Research Framework.

## Purpose

Use this package when drafting the final review paper. It consolidates the current research state while preserving the distinction between verified evidence, candidate interpretations, unresolved hypotheses, and future experimental work.

## Excel workbook structure

The companion workbook `Metaverse_Paper_Writing_Evidence_Master.xlsx` contains:

1. Dashboard — counts, current contribution stack, manuscript status.
2. Primary Papers — PNE001–PNE019 with title, year, venue, DOI/identifier, problem, method, metrics, verification.
3. Closest Reviews — R001–R015 and their implications for non-redundancy.
4. Domain Status — current mining/extraction/reproducibility status across 15 domains.
5. Analysis Done — evidence maturity, deployment maturity, gap taxonomy, comparability, contrary-evidence audit, provenance/fidelity gates.
6. Contrary Evidence — hypotheses that were weakened or invalidated by newer evidence.
7. Benchmark Readiness — seven experimental families and their next gates.
8. Claim Register — safe wording versus claims currently forbidden by the evidence.
9. Artifact Plan — planned figures/tables and readiness.
10. Paper Writing Map — manuscript sections mapped to repository evidence and "do not claim yet" cautions.
11. Read Me — usage and evidence-freeze rules.

Problem → Method/Algorithm → Workload/Dataset → Baseline → Metric → Environment → Evidence → Reproducibility → Deployment → Unresolved Condition.
